# CommitWise Sample Data

This folder contains the exact synthetic test fixtures used for the hackathon demo.

- `sahyadri_bank_savings_xx0937_jun-sep2026.csv` — bank statement
- `nimbus_card_xx4821_statements_jun-sep2026.pdf` — credit-card statement
- `zenith_softworks_payslips_jun-aug2026.pdf` — three payslips
- `2026-06-12_012_shopzone.eml` — email receipt
- `demo-transactions.json` — normalized transaction dataset derived from those fixtures, used as the deterministic demo fallback

All documents are synthetic test data. The app labels the loaded dataset as Demo Data.
